# TKBshot

macOS用のメニューバー常駐型スクリーンショットアプリです（Dockにアイコンは出ません）。ショートカットで範囲選択を始め、撮った画像はPNGで保存すると同時にクリップボードへコピーします。続けて内蔵のエディタで、枠・矢印・文字・番号・モザイクなどの注釈を入れられます。

- **ダウンロード**: [Releases](https://github.com/TKBlabs/TKBshot/releases)（最新版のDMG）
- **製品ページ**: https://apps.tkbtk.com/TKBshot/
- **動作環境**: macOS 26.5以降、Apple Silicon（Intel Macには対応していません）
- **ライセンス**: フリーウェア（個人・商用を問わず無料）

## インストール

1. [Releases](https://github.com/TKBlabs/TKBshot/releases)から最新版の `TKBshot_<バージョン>.dmg` をダウンロードします。
2. DMGを開き、`TKBshot.app` を「アプリケーション」フォルダへドラッグします。
3. 「アプリケーション」フォルダから起動します。メニューバーにカメラのアイコンが表示されます。

アプリとDMGはどちらもAppleの公証（Notarization）を受けています。初回起動時に「インターネットからダウンロードされたアプリケーションです」と確認が出たら「開く」を押してください。

> [!IMPORTANT]
> DMGの中やダウンロードフォルダから直接起動すると、自動アップデートがうまく動かないことがあります。「アプリケーション」フォルダ以外から起動した場合は、TKBshotが移動を勧めます。「移動して起動し直す」を選ぶと、移した先で起動し直します。

### 必要な許可

| 許可（システム設定 →「プライバシーとセキュリティ」） | 使う場面 |
| --- | --- |
| 画面収録 | 撮影すべて（必須）。許可されていないと、撮影時にシステム設定の画面を開きます |
| アクセシビリティ | クリックでウィンドウ内の部品（Webページ部分など）だけを撮るとき |
| 通知 | 撮影後の通知から編集画面を開くとき（初回起動時に確認が出ます） |

## アップデート

自動アップデート（Sparkle）に対応しています。

- 24時間ごとに新しい版を確認します（設定の「更新」でオン・オフできます）。
- メニューバーアイコンの右クリックメニュー「アップデートを確認...」、または設定の「更新」の「今すぐ確認」で、すぐに確認することもできます。

各版の変更点は[Releases](https://github.com/TKBlabs/TKBshot/releases)に載っています。

## 使い方

- **撮影**: ⇧⌘S（設定で変更できます）、またはメニューバーアイコンの右クリックメニュー「スクリーンショットを撮る」。
- **繰り返し撮影**: ⇧⌘R で、直前に撮った範囲と同じ場所をもう一度撮ります。
- **メニューバーアイコンを左クリック**: 画像を開いて編集する画面が出ます（画像のドラッグ＆ドロップ、「画像を選択」、「クリップボードから貼り付け」）。
- **メニューバーアイコンを右クリック**（またはControl＋クリック）: メニューを表示します。

| メニュー | 内容 |
| --- | --- |
| スクリーンショットを撮る | 範囲選択を始めます |
| 画像を開いて編集... | 画像ファイルやクリップボードの画像を編集します |
| 設定... | 設定画面を開きます |
| アップデートを確認... | 新しい版があるか確認します |
| 通知を出す | 撮影後に通知を出し、通知のクリックで編集画面を開きます（オフにすると、撮影後すぐに編集画面を開きます） |
| 終了 | TKBshotを終了します |

## 主な機能

### 撮影

撮影を始めると画面が一時的に止まった状態になるので、すぐに消える表示や切り替わる画面も取り逃しません。複数のディスプレイに対応しています。

- **範囲を撮る**: ドラッグで範囲を選びます。選択中は大きさ（幅 x 高さ px）を表示します。
- **ウィンドウを撮る**: ドラッグせずにクリック（またはSpaceキー）すると、カーソルの下のウィンドウを撮ります。
- **部品だけを撮る**: ブラウザならWebページの表示部分だけ、Finderなら一覧部分だけを撮れます。撮れる範囲を枠と大きさで表示し、マウスホイールで範囲を大きく（ウィンドウ全体まで）／小さく切り替えられます。アクセシビリティの許可が必要です（設定の「ウィンドウキャプチャ」で切り替え）。
- **やめる**: Escキー。

撮った画像は、保存先フォルダ（既定はデスクトップ）に `TKBshot_2026-11-18_10-30-00.png` のような名前のPNGで保存し、同時にクリップボードへコピーします。撮影時にはシャッター音が鳴ります（設定で消せます）。

### 編集画面

撮影後の通知をクリックするか、メニューバーアイコンの左クリックから開きます。

- 道具: 選択・四角・丸・直線・矢印・ペン・文字・番号・ハイライト・モザイク・ぼかし。モードを切り替えずに、描いた図形をそのままドラッグで移動・変形できます。
- 色・太さ・四角の角の丸み・影の有無を選べます。文字は「縁取り」「背景付き」「文字のみ」から選べ、入力に合わせて枠が広がります（ダブルクリックで再編集）。番号は置くたびに 1, 2, 3… と増えます。
- 道具ごとの色や太さなどの設定は、次回起動時にも引き継ぎます。
- 右クリックで、複製・最前面へ・最背面へ・削除・編集結果をコピー・注釈をすべて消す。
- 「完了」（Enter / ⌘S）で保存し、クリップボードにもコピーして閉じます。撮影した画像は元の名前に `_edited` を付けて同じフォルダへ保存します。「別名で保存」（⇧⌘S）で場所と名前を指定することもできます。

## 主なショートカット

### 撮影中

| 操作 | キー |
| --- | --- |
| 撮影を始める | ⇧⌘S（設定で変更可） |
| 直前と同じ範囲を撮る | ⇧⌘R（設定で変更可） |
| カーソルの下のウィンドウ（部品）を撮る | クリック / Space |
| 撮る範囲を大きく／小さく | マウスホイール |
| やめる | Esc |

### 編集画面

| 操作 | キー |
| --- | --- |
| 道具を選ぶ | V 選択 / R 四角 / E 丸 / L 直線 / A 矢印 / F ペン / T 文字 / I 番号 / H ハイライト / P モザイク / B ぼかし |
| 図形を描くときに縦横比固定・45°刻み | ⇧を押しながらドラッグ |
| 描いている図形の位置を調整 | Spaceを押しながらドラッグ |
| 選んだ注釈を1px（10px）動かす | 矢印キー（⇧＋矢印キー） |
| 選んだ注釈を複製 | ⌘D、または⌥を押しながらドラッグ |
| 最前面へ／最背面へ | Home / End |
| 選んだ注釈を削除／すべて消す | Delete / ⇧Delete |
| 元に戻す／やり直し | ⌘Z / ⇧⌘Z |
| 編集結果をクリップボードへコピー | ⌘C |
| 拡大／縮小／100% | ⌘+ / ⌘- / ⌘0 |
| 保存して閉じる | Enter / ⌘S（文字の入力中は⇧Enterで改行） |
| 別名で保存 | ⇧⌘S |
| 選択を解除／閉じる | Esc（選択中は解除、編集済みなら破棄の確認） |
| 確認せずに編集をやめて閉じる | ⌘W |

## 設定

メニューバーアイコンの右クリックメニュー「設定...」から開きます。

| 項目 | 内容 |
| --- | --- |
| ショートカット | 撮影と繰り返し撮影のキー（英字1文字）と修飾キー（⌘ ⌥ ⌃ ⇧） |
| 保存設定 | ファイル名の接頭詞（既定「TKBshot」）、日付をファイル名に付与、保存先フォルダ |
| ウィンドウキャプチャ | 左クリックでウィンドウをキャプチャ（オフにするとクリックで撮影をやめ、ウィンドウはSpaceキーだけで撮ります）、マウス直下の部品（Webページ部分など）を選ぶ |
| マウスカーソル | キャプチャにマウスカーソルを含める |
| シャッター音 | 撮影時にシャッター音を鳴らす |
| 編集画面の起動 | 通知を出してクリックで編集画面を開く、自動で開くときに既存の編集画面を残して新しい画面で開く |
| 起動設定 | ログイン時に自動起動 |
| 更新 | アップデートを自動的に確認、最終確認日時、バージョン、今すぐ確認 |

## 困ったときは

- **撮影できない・真っ黒な画像になる**: システム設定 →「プライバシーとセキュリティ」→「画面収録」でTKBshotがオンになっているか確認してください。アップデート後にうまく動かないときは、一度オフにしてからオンにし直し、TKBshotを起動し直してください。
- **クリックしてもウィンドウ全体しか撮れない**: 設定の「ウィンドウキャプチャ」で「マウス直下の部品（Webページ部分など）を選ぶ」をオンにし、アクセシビリティを許可してください。
- **ショートカットが効かない**: 他のアプリと同じキーになっていないか確認し、設定の「ショートカット」で変えてください。
- **撮影後に通知が出ない**: システム設定 →「通知」でTKBshotの通知を許可してください。
- **自動アップデートが失敗する**: TKBshotが「アプリケーション」フォルダにあるか確認してください。

## プライバシー

撮った画像は指定した保存先フォルダとクリップボードにだけ置き、外部へ送ることはありません。動作の記録（`~/Library/Logs/TKBshot/diagnostics.log`）もこのMacの中にだけ残します。通信するのは、アップデートの確認（apps.tkbtk.com とGitHub）だけです。
