TKBshot

範囲選択から注釈、保存までを最短でつなぐ、メニューバー常駐のスクリーンショットアプリ。

TKBshot — キャプチャ

概要

// overview

TKBshotは、メニューバーから即座に呼び出せるスクリーンショット専用ツールです。 グローバルショートカットで範囲選択を開始し、選択範囲はPNG保存とクリップボードコピーを同時に実行します。

キャプチャ後は内蔵エディタで四角・丸・直線・矢印・ペン・文字・番号・ハイライト・モザイク・ぼかしを追加可能。 撮影時には画面を一時フリーズして選択できるため、オンライン会議中の大事なスライドや一瞬で切り替わる画面も取り逃しにくい設計です。

主な機能

// features
⇧

範囲・ウィンドウ単位キャプチャ

ドラッグ範囲選択に加え、カーソル下のウィンドウや、Webページ部分などウィンドウ内の部品をワンクリックで切り取れます。

↻

繰り返し撮影ショートカット

直前の選択範囲を再利用する専用ホットキーを搭載。定点の連続キャプチャが高速です。

▤

メニューバー常駐

メニューバーから撮影・編集起動・設定を呼び出し。Dockに置かずに常用できます。

✎

内蔵注釈エディタ

四角・丸・直線・矢印・ペン・文字・番号・ハイライト・モザイク・ぼかしを1画面で編集。描いた図形はそのまま移動・変形できます。

⏎

保存先とファイル名を設定

保存先フォルダ、接頭辞、日付付与を設定可能。撮影後はPNG保存とクリップボードコピーを自動実行。

❄

撮影時の画面フリーズ

選択中に画面をフリーズ表示することで、オンライン会議の重要スライドや瞬間表示の情報を逃さず撮影できます。

# TKBshot

スクリーンショットの「撮る」から「共有する」までを、
できるだけ短い動線でつなぐmacOS用アプリです。

## インストール

  • DMGを開き、TKBshot.app を「アプリケーション」フォルダへドラッグします
  • Appleの公証（Notarization）済みのため、そのままダブルクリックで起動できます
  • 初回の撮影時に「画面収録」の許可を求められます（部品単位の撮影にはアクセシビリティの許可も）

## アップデート

  • 24時間ごとに自動で更新を確認し、新しい版があればお知らせします
  • メニューバーアイコンの右クリックメニュー「アップデートを確認...」から手動でも確認できます
  • 自動確認の有無は 設定 → 更新 で切り替えられます

## 動作環境

  • macOS Tahoe 26.5以降
  • Apple Silicon 搭載Mac（Intel Mac非対応）

## 主な機能

  • 範囲選択・ウィンドウ・ウィンドウ内の部品（Webページ部分など）単位のキャプチャ
  • 直前と同じ範囲をもう一度撮る繰り返し撮影ショートカット
  • 撮影と同時にPNG保存とクリップボードへのコピー
  • 四角・丸・直線・矢印・ペン・文字・番号・ハイライト・モザイク・ぼかしの注釈エディタ
